# Compliance Local Pipelines (VS Code Extension)

Extension locale autonome de préparation et d'audit de pipelines de conformité pour cibles locales.

## Caractéristiques
- **Démon local autonome en Go** : communication HTTP/SSE sécurisée sur boucle locale (127.0.0.1) avec jeton cryptographique 256 bits et verrou d'instance unique.
- **Support multi-OS** : binaires Go natifs embarqués pour Windows (x64), Linux (x64) et macOS (arm64/amd64).
- **Zéro dépendance hôte requise** : isolation stricte, aucun prérequis d'installation externe.
- **Audit et Rapports v1** : validation locale conforme au schéma strict de la plateforme Compliance.
